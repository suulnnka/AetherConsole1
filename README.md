# AetherConsole

网页上的梦幻主机(240×180 @ 60fps),规格见 [docs/spec.md](docs/spec.md)。

## 运行

用最新版 Chrome 直接打开 `index.html` 即可(或 `python -m http.server` 后访问)。
开机进菜单,↑↓ / 鼠标选择卡带,Z / Enter / 点击启动,**Esc 返回菜单**,1-4 切换特效(无/扫描线/CRT/半色调)。

## 卡带

### BREAKOUT · 打砖块(阶段一验收 demo)

操作:←→ / A D 移动挡板,Z / J 发球,Enter 开始 / 暂停。

### NIGHT SURVIVOR · 吸血鬼幸存者式生存

操作:WASD / 方向键移动,Enter 开始 / 暂停;武器全自动开火,键盘即可玩(鼠标点击=Z)。

- 击杀掉落经验宝石,升级时三选一:5 种武器(魔弹 / 飞刀 / 圣环 / 月珠 / 落雷,各 5 级)+ 7 种被动(移速 / 生命 / 回复 / 拾取 / 护甲 / 威力 / 急速),最多带 4 件武器
- 敌人 5 种(蝙蝠 / 僵尸 / 幽灵 / 吐息者 / 蛮兵),随时间与关卡增强;定时精英(金环,掉宝箱=直接给随机强化)、蝙蝠潮
- 关卡推进:每关计时结束出 Boss(弹环 + 召唤),击杀过关、回血 25%,进入下一关;4 关后 ENDLESS 循环增强
- 拾取:红心(回血)/ 磁铁(全图吸宝石)/ 宝箱;死亡结算并记录最佳生存时间(localStorage)

### GATE RUNNER · 3D 穿门飞行

操作:鼠标(光标偏离屏幕中心的方向即转向)或 ←→↑↓ / WASD 转向;Enter 开始 / 暂停。画面中央的白点就是你,飞船自动前进,手写 3D 透视投影,无三方库。

- 前方是正方形门:从门洞穿过;碰门框(或错过门洞)即坠毁,扣 1 命并重飞本关
- 关卡(8 关 + 无尽 RANK):横风(门左右移动)、气涌(门上下移动)、窄门、双门连锁、双向漂移、高速关……速度与门形逐关递增
- 从门洞正中穿过得 PERFECT,连击加倍加分;3 条命,最佳成绩记入 localStorage

### STARFALL · 竖版弹幕射击(东方风)

操作:←→↑↓ / WASD 移动,Z / J 按住开火,X / K 符卡炸弹;Enter 开始 / 暂停。

- 4 种杂兵(妖精纵队 / 玉灵环射 / 飞镖俯冲 / 炮车散射)成波推进,**每 4 波出 Boss**(三阶段:旋转环弹 → 双螺旋 → 狂暴环 + 对准弹)
- 小判定点自机;**贴着敌弹 11px 内"擦弹"**(GRAZE)加分;击杀连击(CHAIN)抬升得分倍率
- 火力 P 道具四级(最高五向弹),阵亡掉 1 级火力并清弹;符卡全屏消弹 + 持续伤害
- 打击感:命中停顿 / 受击闪白 / 爆炸粒子 + 冲击波环 / 弹幕生成缩放 / Boss 入场 WARNING 抖屏 / 连击弹字;3 命 2 炸弹,最佳成绩记入 localStorage

### AETHER GP · FC 风伪 3D 赛车

操作:↑ 油门,↓ 刹车,←→ 转向;Enter 开始 / 暂停。逐扫描线透视投影弯道(经典伪 3D 扫描线法),无三方库。

- **检查点续时**:每 2800 单位 +12 秒(上限 60),时间归零结束;起步 3-2-1-GO 倒计时
- 车流躲避:追尾 = 命中停顿 + 火花 + 掉速;**擦身而过 CLOSE +100**;路肩碎石减速抖屏
- 每 2 个检查点进下一 STAGE(白天 → 黄昏 → 夜晚循环):弯更急、车更密、极速更高
- 打击感:撞车红闪 + 命中停顿 · 检查点拱门 + 白闪 · 高速流光与微震 · 山体视差 / 星空
- 最佳成绩记入 localStorage

### PIXEL DASH · 横版无尽跑酷

操作:Z / J / ↑ 跳(按住跳更高,空中再按二段跳),↓ 滑铲 / 空中快落;Enter 开始 / 暂停。

- 障碍:深坑 / 尖刺 / 箱堆 / 高墙(要二段跳)/ 警示低杠(要滑铲);浮台 + 金币弧线
- 手感:土狼时间 + 跳跃缓冲 + 可变跳高;速度随距离成长,每 500M SPEED UP 里程碑
- 金币连击(COMBO)弹字;距离 + 金币计分;最佳成绩(M)记入 localStorage
- 打击感:落地 squash + 尘爆 + 微震 · 二段跳气环 · 滑铲尘尾 · 死亡命中停顿 + 红闪 + 爆炸 · 三层视差(云 / 远山 / 近丘)

### DEEP DROP · 是男人就下 100 层

操作:←→ 移动,Z / J / ↑ 跳,**按住 ↓ 穿过平台下落** / 空中快落;Enter 开始 / 暂停。

- 洞顶尖刺不断逼近,只能不停往下跳;平台 5 种:**岩石 / 冰移(左右滑)/ 龟裂(踩上即碎)/ 尖刺(致命)/ 弹簧(高弹)**
- 落点越靠平台中心越有 **PERFECT 连击**;每 10 层提示,**100 层"真汉子"庆祝后无尽继续**
- 打击感:落地 squash + 平台下陷 · 弹簧拉伸 + 气环 · 龟裂抖动碎裂 · 尖刺死亡命中停顿 + 红闪 · 快落速度线 · 洞壁火把光晕
- 最佳层数记入 localStorage

### MAGIC TOWER · 21 层魔塔

操作:方向键 / WASD 移动(按住连走),撞上怪物弹出**战斗预测**,Z 确认开打,X 取消;Enter 暂停。

- 致敬 21 层魔塔(原作者开放版权):经典战斗公式(每回合玩家先攻,实损 = (回合数-1) × max(0, 敌攻-我防),魔法系怪物先攻),前期怪物数值照搬原版,后期按同公式平衡
- 21 层原创排布地图:三色钥匙开门、红蓝宝石、四级剑盾(铁→银→骑士→圣)、血瓶四档、楼层商店(100 金换 600 血 / +4 攻 / +4 防)、5 层仙子祝福、9 层获得**飞行翼**(楼梯上按 X 在已到过的楼层间传送)
- **战斗预测面板**显示回合数与实损,致死战斗禁止确认,防手滑;14 层宝物层、18 层圣剑、20 层红龙、21 层魔王
- 进度自动存档(localStorage),标题页可继续;平衡用 `node tools/mt-check.mjs` 校验(地图连通性 / 钥匙收支 / 全清 HP 曲线)

### TIDY UP! · 双屏整理

操作:方向键 / WASD 移动,Z / 左键 捡起 / 放上货架,X / 右键 手动切屏;Enter 开始 / 暂停。

- 两个屏幕:**地板屏**(仓库,物品散落)与**货架屏**(三排货架,各归一类:红书 / 绿瓶 / 蓝盒)
- **最多同时拿 5 件**:拿到第 5 件自动切到货架屏;把手里物品放空后自动切回地板屏;X 随时手动切
- 放对货架 +100 起步连击加分;放错货架算失误(-50,断连击);全部归位过关,按用时与失误评 S/A/B/C
- 关卡递进:物品 6 → 18 件,木箱障碍渐多;鼠标可直接点物品 / 点货架空位(机器人够得着才捡得到)

### PUFF VOLLEY · 圆球兽排球

操作:←→ / A D 移动,↑ / W 跳;Enter 开始 / 暂停;←→ 选难度(EASY / NORMAL / HARD)。

- 致敬皮卡丘排球的核心手感:**无攻击键**,身体碰到球自动出拳,出拳方向 = 球在身体哪一侧;同一玩家连续出拳有冷却
- 球撞两侧墙壁反弹、球网碰撞含坐网弹起;落地即失分,**先得 15 分**获胜;发球方得分后轮换发球
- AI 前向模拟球的轨迹**预测落点**,按难度限制反应间隔 / 移速 / 误差 / 起跳率;对拉有 RALLY 计数,最佳回合记录在 localStorage

### PALE CITADEL · 波次制 3D FPS

操作:WASD 移动,**鼠标瞄准(水平 + 俯仰,相对位移:鼠标动多少视角转多少)**,点击画面锁定指针(`unadjustedMovement` 原始输入,Esc 释放,锁定丢失自动暂停;未锁定时同样按相对位移转向,仅光标到窗口边缘后为止,画面内有提示),左键 / Z 射击(无限弹药,准星即屏幕中心),右键 / X 跳;Enter 开始 / 暂停。纯 JS 软件 3D:z-buffer 多边形光栅 + 逐行地面投影,无三方库。

- 美术:白底天空;建筑为**线描轮廓 + 非常浅的蓝抖动填充**(Bayer 有序抖动),立面 / 地面均按远近分层(近浅蓝 → 中冰蓝×雾 → 远雾×白),描边随距离淡出,远景颜色层次分明;敌人用黄红橙四色,白底上格外醒目
- 一张 240×240 城市大图(比沙 2 大得多):中央高台广场 + 柱廊 + **方形螺旋塔**(沿塔身盘旋而上到 8.5m 环廊)、南北城门楼、4 条屋顶天桥、仓库集装箱区(阶梯院上屋顶)、老城九街区巷网、台地花园、三层看台竞技场;地面街道与屋顶天桥多层路线四通八达,自动上台阶(≤0.55m)登梯,高处跌落有重力
- **波次制,一图到底**:消灭全部敌人后仍在该图进入下一波,敌人更多更强(数量 4+4×波,血量 / 伤害随波成长);敌人 4 种——追猎者(琥珀,冲锋)、蜂群(黄,飞行环绕,克制蹲点)、哨兵(橙,保持距离侧移射击)、巨像(红,重甲近战);BFS 流场寻路会爬楼梯追人
- 射击:无限弹药全自动步枪,准星沿视线判定 + 爆头 ×1.8;曳光 / 火花 / 枪口焰 / 后坐力与开火上抬;受击脱战后缓慢回血,清波 +30 HP
- HUD:动态扩散准星 + 命中标记(击杀变红)、血条、波次 / 残敌 / 分数、右上雷达小地图(建筑分层灰阶 + 敌色圆点),残敌 ≤5 时屏幕边缘出现方向指示;最佳成绩仅本次会话内保留(无存档功能)

## 创作工具(阶段二)

`tools/index.html` 为工具入口(Chrome 直接打开即可),包含:

- **字体编辑器** `tools/font-editor.html` — 12×12 位图字形编辑(规格 §11.3):
  编辑网格 14×14 = 主区 12×12 + 左侧 2px 入侵区(渲染时向左溢出,压入前一字符的间隔)+ 下侧 2px 尾部区(向下溢出);
  内置全套 ASCII 默认字体(英文 / 数字 / 标点),可添加中文、假名、希腊字母、符号等任意字符;
  实时预览与上下文条展示入侵 / 尾部溢出效果;导出 `font.af.json` 与 `font.bin`(AFNT v1:码点表 u32 LE + 每字形 14 行 × u16 位图)。
- **图形编辑器** `tools/gfx-editor.html` — 精灵 / Tile / 地图三合一(规格 §11.1):
  256×256 索引色精灵图(16 色 RGB565 调色板,下标 0 = 透明);tile 为 8×8(32×32 = 1024 个),
  精灵为 8 倍数任意尺寸矩形(自动寻找空闲位置放置);地图条目 u16 = tile 索引 + 水平/垂直翻转位(0xFFFF = 空);
  导出项目 JSON、精灵图 PNG / `spritesheet.bin`、地图 JSON / `map.bin`;支持 PNG 量化导入;草稿自动保存于浏览器。
